# JSON 읽기 카드

> **JSON은 이름표 붙은 상자, 점(.)은 상자를 여는 길**
> JSON을 직접 쓸 일은 거의 없어요. **어느 칸에 원하는 값이 있는지 찾아서 Claude에게 알려 주는 것**까지만 하면 돼요.

## 진짜 응답 하나 (Frankfurter 환율, 2026-10-19 기준)

한 줄로 오면 이렇게 생겼어요.

```json
{"amount":1.0,"base":"USD","date":"2026-10-19","rates":{"KRW":1329.49}}
```

줄을 바꿔 보면 상자 구조가 보여요.

```json
{
  "amount": 1.0,
  "base": "USD",
  "date": "2026-10-19",
  "rates": {
    "KRW": 1329.49
  }
}
```

## 규칙 4가지

| 기호 | 비유 | 이 예시에서 |
| --- | --- | --- |
| `{ }` | **상자** | 전체가 상자 하나, `rates`도 그 안의 작은 상자 |
| `"이름": 값` | **이름표 붙은 칸** | `"date"` 칸에 `"2026-10-19"` |
| `[ ]` | **번호 붙은 줄** (목록, 0번부터) | 공휴일 API가 이렇게 와요 |
| `.` | **상자 열고 들어가기** | `data.rates.KRW` → 1329.49 |

## 목록(`[ ]`)은 번호로 꺼내요

공휴일 API 응답(줄임):

```json
[
  { "date": "2026-12-25", "localName": "기독탄신일", "name": "Christmas Day" },
  { "date": "2027-01-01", "localName": "새해", "name": "New Year's Day" }
]
```

- 첫 번째 공휴일 이름 → `list[0].localName` → 기독탄신일
- 두 번째 날짜 → `list[1].date` → 2027-01-01
- **번호는 0부터** 세요. 첫 번째가 0번이에요

## 꺼내기 퀴즈 (Slack에 답 올리기)
1. 환율 응답에서 기준 날짜는? → `data.____`
2. 원화 환율은? → `data.____.____`
3. 공휴일 목록에서 첫 번째 날짜는? → `list[_].____`
4. 날씨 응답 `{"current":{"temperature_2m":17.3}}`에서 기온은? → `data.____.____`

정답: 1) `data.date` 2) `data.rates.KRW` 3) `list[0].date` 4) `data.current.temperature_2m`

## 브라우저에서 보기 좋게
- **Chrome·Edge**: JSON 주소를 열면 위에 나오는 **"보기 좋게 표시(Pretty-print)"** 체크
- **Firefox**: 자동으로 접었다 폈다 할 수 있게 보여 줘요
- 어디서든: `API_주문_시뮬레이터.html`에서 값을 누르면 꺼내는 길이 나와요
