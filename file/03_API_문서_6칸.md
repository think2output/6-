# API 문서 읽는 6칸

> 사이트마다 메뉴 이름은 달라도, 보는 곳은 같아요. 이 6칸만 채우면 직접 주소를 만들 수 있어요.

| 칸 | 찾을 것 | 사이트에서 흔히 부르는 이름 | 내 API |
| --- | --- | --- | --- |
| ① 기본 주소 | 모든 주소의 앞부분 | Base URL | |
| ② 메뉴 | 무엇을 받을 수 있나 | Endpoints, API Reference | |
| ③ 옵션 | 주소 뒤 `?이름=값` | Parameters, Query | |
| ④ 응답 모양 | 어떤 JSON이 오나 | Response, Example | |
| ⑤ 키 | 가입·키가 필요한가 | Authentication, API Key | |
| ⑥ 규칙 | 무료 범위·출처 표기 | Pricing, Terms, Rate limit | |

## 예시: Open-Meteo 날씨로 채워 보면
| 칸 | 내용 |
| --- | --- |
| ① 기본 주소 | `https://api.open-meteo.com/v1/` |
| ② 메뉴 | `forecast` (예보) |
| ③ 옵션 | `latitude`, `longitude`, `current=temperature_2m,...`, `timezone` |
| ④ 응답 모양 | `{ "current": { "temperature_2m": 17.3, "weather_code": 1, ... } }` |
| ⑤ 키 | 필요 없음 |
| ⑥ 규칙 | 비상업적 용도 무료, 하루 1만 회 이하 권장, 출처 표기 요청 |

## 사이트 볼 때 주의
- **Frankfurter**: 사이트 예시는 새 버전 `v2`(`/v2/rates?base=usd&quotes=krw`)예요. 샘플은 `v1`을 쓰는데, v1도 계속 쓸 수 있다고 안내돼 있어요
- **Nager.Date**: 샘플은 `v3`(한국어 이름 `localName` 포함)을 써요. 새 `v4`는 영어 이름만 줘요
- **REST Countries(나라 정보)**: 2026년에 예전 무료 주소가 중단되고 **키가 필요한 방식**으로 바뀌었어요. 무료 API는 이렇게 예고 없이 바뀌기도 해요 → 그래서 실패 화면이 필요해요
- 더 찾고 싶으면 GitHub의 **public-apis** 목록에서 표의 **Auth: No / HTTPS: Yes / CORS: Yes** 세 칸을 확인하세요. 셋 다 맞아야 HTML에서 바로 쓸 수 있어요

## 3교시 할 일
1. 내 서비스에 쓸 API를 고른다 (샘플에 있는 것도 OK)
2. 위 6칸 표를 채운다
3. Open-Meteo라면 문서 페이지에서 체크박스로 주소를 만들어 본다
4. 만든 주소를 브라우저 주소창에 붙여 JSON이 오는지 확인한다
5. 6칸 표를 내 레포 `README.md`에 붙여 넣는다
