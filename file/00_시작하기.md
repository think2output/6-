# D6 · 10/21(수) · 무료 API로 나만의 서비스 만들기

> 오늘의 한 줄: **API = 주소로 주문하면 데이터가 배달된다**
> 오늘은 완성 파일을 나눠 주지 않아요. **규칙(CLAUDE.md)과 프롬프트로 직접 만들고, 규칙대로 됐는지 검사**해요.

## 오늘 끝나면
- API와 API 키의 차이를 비유로 설명할 수 있다 (주문 창구 vs 회원 카드)
- JSON에서 원하는 값을 찾아 `data.rates.KRW`처럼 꺼내는 길을 말할 수 있다
- **규칙 만드는 규칙 5가지**로 검사할 수 있는 규칙을 쓸 수 있다
- 바이브 코딩으로 만든 API 화면에서 AI 실수(규칙 위반)를 찾고, **규칙 한 줄로 고칠 수 있다**
- 키 없는 API를 쓰는 **나만의 서비스**를 **GitHub Pages 링크**로 공개했다

## 준비물
- VS Code + Claude Code (D3), Git + GitHub 계정, `git-practice` 레포 (D5)
- **API 키는 필요 없어요.** 오늘 API는 전부 회원 카드 없이 주문되는 창구예요

## 오늘의 말 사전
| 말 | 비유 | 뜻 |
| --- | --- | --- |
| API | 주문 창구 | 다른 회사 서버에 데이터를 주문하는 통로 |
| API 키 | 회원 카드 | 가입해야 받는 출입증. 오늘은 **필요 없음** |
| 엔드포인트 | 메뉴판의 메뉴 | API 안에서 무엇을 받을지 정한 주소 |
| 파라미터 | 주문 옵션 | 주소 뒤 `?이름=값` |
| JSON | 이름표 붙은 상자 | API가 보내 주는 데이터 모양 |
| fetch | 주문 보내기 | 코드에서 API를 부르는 명령 |
| Issue | 할 일 카드 | GitHub 레포에 붙이는 포스트잇 |
| GitHub Pages | 무료 전시장 | 내 HTML을 링크로 공개해 주는 GitHub 기능 |

## 막히면
1. 화면이 하얗다 → `F12` → **Console**의 빨간 글씨를 통째로 Claude Code에 붙여 넣기
2. API가 안 온다 → 휴대폰 핫스팟 → 그래도 안 되면 강사에게 (예시 응답 있음)
3. 그래도 막히면 빌드 버디 → 스쿼드 채널 → 강사
