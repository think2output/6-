## 14:10 레포와 뼈대 만들기 (프롬프트로)
1. GitHub에서 새 레포 `my-service` (**Public**, README 체크 X) → clone → VS Code로 열기
2. `CLAUDE_API규칙.md`의 규칙(오전에 추가한 '실수에서 배운 규칙' 포함)을 `my-service/CLAUDE.md`에 붙여 넣고, **내 서비스 규칙 2줄을 직접** 추가 — `08_규칙_만드는_규칙.md`의 틀로
   ```
   ## 내 서비스 규칙
   - (해라/하지 마라) ___ (왜: ___) → 검사: ___
   - (해라/하지 마라) ___ (왜: ___) → 검사: ___
   ```
   예(PO 출장 준비): "나라를 바꾸면 날씨·환율·공휴일이 모두 그 나라 것으로 바뀐다 (왜: 하나만 바뀌면 사용자가 헷갈림) → 검사: 일본→미국으로 바꿔 세 카드 확인"
3. Claude Code에게:
```
나는 ___(직군)이고 "___(서비스 한 줄)" 을 만들 거야.
이 레포에 아래를 만들어 줘. 아직 기능은 만들지 마.
1) index.html: 서비스 이름과 한 줄 소개만 있는 빈 화면 (CLAUDE.md 규칙의 API 상자 자리 포함)
2) README.md: 서비스 소개, 기능 3줄, API 문서 6칸 표(빈칸)
3) .github/ISSUE_TEMPLATE/기능.md: 제목, 완료 기준 체크박스, 쓰는 API
4) .github/pull_request_template.md: 맨 위 "Closes #", 내가 직접 확인한 것 체크박스
5) .gitignore: .env 와 CLAUDE.local.md 제외
기능 3줄은 완료 기준이 화면에서 눈으로 확인되는 문장으로 제안해 줘.
```
4. 만든 파일 읽어 보고 커밋·푸시: `"[직군] D6: 뼈대"`
5. 기능 3줄 → GitHub Issues에서 **기능** 양식으로 3장
