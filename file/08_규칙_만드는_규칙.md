# 규칙 만드는 규칙 (D6)

> 바이브 코딩에서 사람이 쓰는 가장 중요한 글은 **규칙(CLAUDE.md)** 이에요.
> 좋은 규칙은 AI가 따라 하기 쉽고, **사람이 검사하기 쉬워요.** 규칙 한 줄 = 검사 한 줄.

## 규칙을 쓸 때 지킬 5가지

| # | 규칙 만드는 규칙 | 나쁜 예 | 좋은 예 |
| --- | --- | --- | --- |
| 1 | **검사할 수 있게 쓴다** — 예/아니오로 확인되는 문장 | 화면을 깔끔하게 만든다 | 카드마다 로딩 중 문구와 실패 안내가 보인다 |
| 2 | **하지 말 것도 쓴다** — 그리고 대신 할 것 | (안 씀) | "실시간"이라고 쓰지 않는다. 대신 기준 날짜를 보여 준다 |
| 3 | **이유를 한 줄 붙인다** — AI가 비슷한 상황에도 적용해요 | API 키를 쓰지 않는다 | API 키를 쓰지 않는다 (왜: HTML은 누구나 코드를 볼 수 있어서) |
| 4 | **짧게, 제자리에 둔다** — 같은 말 반복·반대 말 금지 | 루트와 폴더 CLAUDE.md에 같은 규칙을 다르게 씀 | 레포 공통은 루트, 이 폴더만은 폴더 CLAUDE.md, 나만은 CLAUDE.local.md |
| 5 | **실수가 나오면 규칙을 고친다** — 실수 1개 → 규칙 1줄 | 같은 실수를 매번 말로 고침 | "공휴일 이름은 localName(한국어)으로, 없으면 name" 한 줄 추가 |

## 규칙 한 줄 틀
```
- (해라/하지 마라) ______ . (왜: ______ ) → 검사: ______
```
예:
```
- API 주소는 파일 맨 위 한 곳에 모으고 // 🔌 를 단다. (왜: 어디가 API인지 바로 찾으려고) → 검사: Ctrl+F 🔌
```

## 자기 점검 — 이 규칙 괜찮을까?
- [ ] 이 문장으로 **체크박스**를 만들 수 있나? (못 만들면 1번 위반)
- [ ] AI가 이 규칙을 **어기는 모습**을 상상할 수 있나? (상상 안 되면 너무 뻔하거나 모호한 규칙)
- [ ] 다른 CLAUDE.md와 **부딪히지** 않나? (4번)
- [ ] 전체 규칙이 **10줄 안쪽**인가? (길면 AI도 사람도 안 읽어요)

## 오늘 쓴 "API 화면 규칙"을 뜯어보면
| 규칙 | 몇 번을 썼나 | 검사 |
| --- | --- | --- |
| 키가 필요한 API는 만들지 말고 알려 줘 | 2 하지 말 것 + 대신 할 것 | 주소에 `key=` 없음 |
| API 주소는 맨 위 + `// 🔌` | 1 검사할 수 있게 | ① 🔌 표시 |
| 화면 맨 아래 API 상자 | 1 | ② API 상자 |
| 로딩 중 / 실패 화면 | 1 | ③ 실패 화면 |
| 출처 · 기준 날짜, "실시간" 금지 | 1·2 | ④ 출처·기준 날짜 |
| 커밋은 제안만 | 2 | 내가 커밋했나 |

→ **검사 4가지는 규칙에서 나왔어요.** 규칙을 잘 쓰면 검사표가 저절로 생겨요.

## 연습 — 나쁜 규칙 고치기 (11:05, Slack에 답)
1. "에러 처리 잘해 줘" →
2. "예쁘게 만들어 줘" →
3. "API 키 쓰지 마" →
4. "환율 정확하게" →
5. "코드 깔끔하게 정리해" →

예시 답 (강사 공개 후 비교)
1. 주소가 틀리거나 응답이 없으면 카드 안에 "불러오지 못했어요"와 에러 내용을 보여 준다
2. 글자와 배경 대비는 4.5:1 이상, 본문 글자는 15px 이상, 휴대폰 폭(360px)에서 가로 스크롤이 없다
3. 키가 필요한 API는 쓰지 않는다 (왜: HTML은 누구나 볼 수 있음). 필요하면 멈추고 알려 준다
4. 환율 옆에 기준 날짜를 함께 보여 주고, "실시간"이라고 쓰지 않는다
5. API 주소는 맨 위 `API` 한 곳에만 두고, 같은 일을 하는 함수는 하나로 합친다

## 실수 → 규칙 고치기 (12:05)
오전에 찾은 AI 실수를 **규칙 한 줄**로 바꿔 `d6-api/CLAUDE.md` 맨 아래 `## 실수에서 배운 규칙`에 추가해요.
```
## 실수에서 배운 규칙
- (10/21) 공휴일 이름은 localName(한국어)으로 보여 주고, 없으면 name. (왜: 사용자가 한국인) → 검사: 화면에 한국어 이름
```
그다음 같은 프롬프트로 다시 만들어 보고, 이번엔 지켰는지 확인해요.
